# Интерфейс оператора БКМ (Беспилотной Коммунальной Машины)

Это веб-приложение, созданное на основе Vite и Vue 3 для управления беспилотной коммунальной машиной. Проект использует Bootstrap для стилизации интерфейса и дополнительные зависимости для улучшения взаимодействия с пользователем. Приложение позволяет оператору отслеживать и управлять ключевыми функциями машины в реальном времени.

## Установка

Для установки приложения выполните следующие шаги:

1. Клонирование репозитория

    ```bash
    git clone https://github.com/sibadi-robotics/bkm_op_interface.git
    ```

2. Переход в директорию проекта

    ```bash
    cd bkm_op_interface
    ```

3. Установка зависимостей.
Убедитесь, что у вас установлен [Node.js](https://nodejs.org/en), затем выполните команду для установки всех необходимых пакетов:

    ```bash
    npm i
    ```

## Запуск в режиме разработки

Для запуска приложения с горячей перезагрузкой:

```bash
npm run dev
```

## Сборка проекта для продакшена

```bash
npm run build
```
